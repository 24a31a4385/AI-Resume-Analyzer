# AI Resume Analyzer 🚀

✨ A smart web application that analyzes resumes and provides useful suggestions along with a score.

## 🌐 Live Demo
🔗 https://24a31a4385.github.io/AI-Resume-Analyzer/

---

## 🚀 Features

✔️ Resume Analysis  
✔️ Skill Detection  
✔️ Section Extraction (Education, Projects, Experience, Interests)  
✔️ Smart Suggestions  
✔️ Resume Score (out of 100)  
✔️ Progress Bar Visualization
