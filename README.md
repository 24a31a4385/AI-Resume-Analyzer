# AI Resume Analyzer 🚀

✨ A smart web application that analyzes resumes and provides useful suggestions along with a score and progress bar.

---

## 🌐 Live Demo
🔗 [Click here to view live project](https://24a31a4385.github.io/AI-Resume-Analyzer/)

---

## 🚀 Features

✔️ Resume Analysis  
✔️ Skill Detection  
✔️ Section Extraction (Education, Projects, Experience, Interests)  
✔️ Smart Suggestions  
✔️ **Resume Score (out of 100) with Progress Bar**  
✔️ Clean & Interactive UI

---

## 🛠️ Tech Stack

- HTML  
- CSS (gradient + card style)  
- JavaScript (Score & Progress bar)

---

## 💡 How to Use

1. Paste your resume in the text box  
2. Click on **Analyze**  
3. View **score, sections, and suggestions** along with progress bar
